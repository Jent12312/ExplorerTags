# 🎨 ExplorerTags for Windows 10/11

Расширение для Проводника Windows, позволяющее окрашивать папки в кастомные цвета и присваивать им теги проектов с мгновенным обновлением.

![Demo](https://via.placeholder.com/800x400.png?text=ExplorerTags+Demo)

## ✨ Особенности
- **Мгновенное применение:** Цвета и теги применяются за 0.1 секунды благодаря прямому вызову WinAPI.
- **Поддержка кастомных иконок:** Автоматически подтягивает любые файлы `.ico` из папки `Icons`.
- **Независимость:** Можно менять цвет отдельно от тега.
- **Безопасность:** Интерфейс вынесен в отдельный процесс C# (WPF), исключая вылеты `explorer.exe`.
- **Группировка в Проводнике:** Поддержка родных колонок Windows для сортировки по тегам.

## 🛠️ Технологии
- **C++ (Win32 / COM / Shell API):** Контекстное меню и обработчик свойств (Property Handler).
- **C# (WPF / .NET 8):** Графический интерфейс настройки папок.
- **SQLite:** Локальное хранение пользовательских тегов.

## 🚀 Установка
Скачайте готовый `ExplorerTags_Setup_v1.0.exe` со страницы [Releases](../../releases) и запустите.
