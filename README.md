# 🎨 ExplorerTags for Windows 10/11 (v2.0 Rust Edition)

[![Rust](https://img.shields.io/badge/Language-Rust%202021-DEA584?style=flat-square&logo=rust)](https://www.rust-lang.org/)

**ExplorerTags** — сверхбыстрое, легковесное расширение для Проводника Windows, позволяющее окрашивать папки в любые цвета спектра, присваивать теги проектов с отображением в родных колонках Windows Explorer, мгновенно просматривать файлы по клавише **Пробел** (macOS QuickLook) и управлять всем через компактный значок в системном трее.

Полностью переписано на **Rust** с нативным интерфейсом на **Slint** — холодный запуск за 10 мс, нулевое потребление памяти в фоне, без тяжелых рантаймов (.NET, Electron, WebView2).

---

## 📜 История проекта: эволюция от C++/C# к чистому Rust

Изначально **ExplorerTags v1.0** разрабатывался как связка расширения оболочки на **C++** (Win32 COM In-Process DLL с полноразмерным движком `sqlite3`) и отдельного диалогового окна настроек на **C# (.NET 8 WPF)**.

Хотя первая версия решала базовую задачу разметки папок, она несла с собой компромиссы: тяжеловесный рантайм .NET, внешние зависимости, медленный холодный старт и раздутый размер дистрибутива.

В версии **2.0** архитектура была переосмыслена и полностью переписана с нуля:
* 🦀 **100% Rust** — модульный Cargo-воркспейс (`crates/`) с безопасной работой с памятью, мгновенной компиляцией и отсутствием сторонних рантаймов.
* ⚡ **Slint вместо WPF** — сверхбыстрый нативный GUI Fluent Design с аппаратным ускорением, открывающийся за доли миллисекунды.
* 📂 **Отказ от внешнего SQLite в пользу NTFS File ID** — переименование папок отслеживается на уровне файловой системы, а теги читаются мгновенно без блокировок БД.
* 🚀 **Новые возможности v2.0** — QuickLook по клавише Пробел, программный HSL-генератор иконок прямо в памяти и трей-ассистент управления проектами.

## ⚡ Ключевые возможности

### 🎨 1. Студия цвета папок (RGB / HSL / Нативная палитра)
* **Перекраска «на лету» (крейт `image`):** Берет эталонную векторно-растровую иконку папки Windows 11 и программно тонирует её в любой оттенок радуги прямо в памяти, сохраняя светотени, реалистичный градиент и белый лист внутри.
* **Генерация полноценного 8-слойного `.ico`:** Автоматически создает файл с полным набором системных разрешений — от 16×16 до 256×256 пикселей.
* **Интуитивный выбор цвета (без обязательного ввода HEX):**
  * 🎨 **Полная палитра Windows (`ChooseColorW`)**: вызов системного спектрального круга с плавной регулировкой яркости.
  * 🎛️ **Интерактивные ползунки HSL**: плавное изменение оттенка (0°–360°) и насыщенности/яркости (25%–80%) с моментальным живым обновлением иконки папки в шапке окна.
  * 🎯 **24 дизайнерских оттенка Windows 11**: разбиты на три аккуратные палитры:
    * *Яркие акценты:* Красный, Оранжевый, Янтарный, Изумрудный, Бирюзовый, Небесный, Синий, Фиолетовый.
    * *Пастельные:* Коралл, Персик, Лайм, Мята, Аквамарин, Лаванда, Пудра, Орхидея.
    * *Глубокие / Строгие:* Бордо, Терракота, Олива, Темно-зеленый, Индиго, Баклажан, Шоколад, Грифель.
  * 📋 **Быстрая вставка HEX**: компактное поле для вставки кода из Figma, браузера или буфера обмена.
* **Каталог готовых иконок:** 50 тщательно отрисованных иконок папок в адаптивной сетке (Fluid Auto-fill Grid).

### 🔍 2. Быстрый предпросмотр по клавише «Пробел» (macOS QuickLook)
* **Мгновенный отклик (< 15 мс):** Выделите любой файл на Рабочем столе или в Проводнике и нажмите **Space (Пробел)**.
* **Поддержка форматов:**
  * 🖼️ *Изображения:* `.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`, `.ico`, `.svg` и др.
  * 📄 *Код и текст:* `.rs`, `.cpp`, `.c`, `.py`, `.js`, `.ts`, `.json`, `.toml`, `.md`, `.txt`, `.log`, `.yaml`, `.ini` и др.
  * 📦 *Файлы других типов:* отображение размера, даты и метаданных.
* **Асинхронная архитектура (без системных блокировок):** Запрос через Shell COM выполняется в фоновом потоке вне цикла низкоуровневого хука (`WH_KEYBOARD_LL`), исключая ошибки `RPC_E_CANTCALLOUT_ININPUTSYNCCALL`.
* **Умный Toggle и фильтрация:**
  * Повторный **Space** или **Esc** моментально закрывает окно.
  * Нажатие **Space** на другом файле переключает предпросмотр на лету без закрытия окна.
  * При переименовании файла в Проводнике нажатие клавиши Пробел не перехватывается, позволяя нормально вводить текст.
  * Окно имеет флаг `always-on-top: true`, благодаря чему гарантированно всплывает над Проводником.

### 🏷️ 3. Интеграция с Проводником и родная колонка «Тег проекта»
* **Собственный обработчик свойств (`IPropertyStore`):** Интегрируется в системную оболочку Windows Shell.
* **Колонка в таблице папок:** В колонке **«Тег проекта»** мгновенно отображается назначенный тег.
* **Сортировка и группировка:** Папки можно группировать и сортировать по проектам стандартными средствами Проводника.
* **Раздельное управление:**
  * Снять только цвет, сохранив тег.
  * Снять только тег, сохранив цвет.
  * Полный сброс папки к стандартному системному виду.

### 🛡️ 4. Защита тегов при переименовании (NTFS File ID)
* Для каждой папки считывается ее уникальный аппаратно-независимый 128-битный идентификатор `FILE_ID_128` файловой системы NTFS.
* Если вы переименуете папку или переместите её в другое место диска, связь с тегом и историей в `registry.json` не теряется.

### ⚙️ 5. Фоновый ассистент в системном трее (`explorer-tags-tray`)
* Иконка в области уведомлений панели задач (рядом с системными часами).
* **Левый клик:** Окно глобальных параметров на Slint:
  * Список всех размеченных папок на компьютере с возможностью перехода в них в один клик или снятия тегов.
  * Управление списком тегов (добавление, удаление).
  * Переключатели QuickLook и автозагрузки при старте Windows.
  * Очистка дискового кэша сгенерированных иконок.
  * Интерактивная тестовая перекраска папок.
* **Правый клик:** Контекстное меню быстрого доступа (Параметры, Папка с иконками, Выход).
* **Автовосстановление:** Поддержка системного события `TaskbarCreated` — значок автоматически восстанавливается при перезапуске `explorer.exe`.

## 🏛️ Архитектура проекта

```
ExplorerTags/
├── crates/
│   ├── explorer-tags-core/      # Ядро: работа с desktop.ini, NTFS File ID,
│   │                            # генерация/тонирование .ico (крейт image), реестр
│   ├── explorer-tags-shell/     # Легковесная COM In-Process DLL (~160 КБ):
│   │                            # IExplorerCommand (меню) + IPropertyStore (колонки)
│   ├── explorer-tags-ui/        # Нативный Slint GUI для настройки конкретной папки:
│   │                            # ChooseColorW, HSL-слайдеры, сетка 50 иконок
│   └── explorer-tags-tray/      # Фоновый процесс панели задач:
│                                # tray-иконка, окно параметров, QuickLook (Space hook)
├── Icons/                       # 50 оригинальных цветовых и стилевых иконок папок
├── res/                         # Схема свойств Windows (PropertySchema.propdesc)
└── installer.iss                # Скрипт Inno Setup для сборки чистого дистрибутива
```

## ⌨️ Горячие клавиши и управление

| Действие | Где работает | Что происходит |
|---|---|---|
| **Space (Пробел)** | Проводник / Рабочий стол | Открыть быстрый предпросмотр выделенного файла (QuickLook) |
| **Space** (повторно) | Проводник / Окно QuickLook | Закрыть предпросмотр (Toggle) |
| **Esc** | В любом месте | Закрыть предпросмотр QuickLook |
| **ПКМ по папке** | Проводник Windows | Пункт меню **«🎨 Настроить папку...»** |
| **ЛКМ по иконке трея** | Панель задач (возле часов) | Открыть окно глобальных параметров ExplorerTags |
| **ПКМ по иконке трея** | Панель задач (возле часов) | Контекстное меню (Параметры, Иконки, Выход) |

## 🔨 Сборка из исходников

### Требования
* **ОС:** Windows 10 или Windows 11 (64-bit).
* **Rust:** версия 1.80+ (target `x86_64-pc-windows-msvc`).
* **Visual Studio Build Tools / MSVC C++**.
* **Inno Setup 6 / 7** (для создания дистрибутива `Setup.exe`).

### Пошаговая сборка

1. **Клонируйте репозиторий:**
   ```powershell
   git clone https://github.com/Jent12312/ExplorerTags.git
   cd ExplorerTags
   ```

2. **Запустите тестирование всех модулей:**
   ```powershell
   cargo test --workspace
   ```

3. **Соберите оптимизированные релизные бинарники:**
   ```powershell
   cargo build --release
   ```

4. **Соберите установочный пакет через Inno Setup:**
   ```powershell
   & "C:\Program Files\Inno Setup 7\ISCC.exe" installer.iss
   ```

Готовый файл установщика появится в:  
📁 `InstallerOutput\ExplorerTags_Setup_v2.0.exe`

## 📦 Установка

1. Запустите собранный установщик **`ExplorerTags_Setup_v2.0.exe`**.
2. Установщик:
   * Скопирует компоненты в `%APPDATA%\ExplorerTags\`.
   * Зарегистрирует COM DLL для меню и колонок Проводника через `regsvr32`.
   * Пропишет автозапуск трей-ассистента в реестре Windows (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
   * Сразу запустит `explorer-tags-tray.exe` в панели задач.
3. Всё готово к работе! Никаких перезагрузок системы не требуется.
